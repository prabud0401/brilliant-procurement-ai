## Bug (found on the hosted app)
`LlmClient.classify()` exists in all providers but is **never called**. A document uploaded without a type (UI "auto-detect", API with no `doc_type`) and every email-intake document is stored as `doc_type="other"`, the extraction prompt is sent "Document type: other", the model echoes `other`, and the document stays `other` and lands in review. Extracted values were otherwise correct.
